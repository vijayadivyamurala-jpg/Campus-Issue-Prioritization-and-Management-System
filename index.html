FAQs

Questions users usually ask first

How do I raise a complaint quickly?

Open the User Portal, sign in as a student or staff member, and submit the issue form with the problem details, location, and optional photo.

How will I know my complaint was submitted?

As soon as you report an issue, the system creates a unique issue ID so you can recognize and track it later.

Where can I check the current status?

After login, open the Live Tracking page to see whether your issue is New, In Progress, or Resolved along with department assignment.

Can I add a photo when the issue needs proof?

Yes. The reporting page allows an optional photo upload, which is useful for damaged infrastructure, hostel problems, and maintenance issues.

What happens after I submit the complaint?

The admin reviews the complaint, assigns priority, routes it to the correct department, and updates the status as the work progresses.

Which complaints should I report here?

You can use this portal for infrastructure, electrical, civil, hostel, lab, classroom, internet, and similar campus support issues.
